# 🎓 Student Registration Form

A modern, responsive student registration form built using **HTML, CSS, and JavaScript**.  
This project features a clean UI, animated background, floating labels, real-time validation, and interactive user feedback.

---

## ✨ Features

- Responsive and modern UI design
- Animated gradient background with floating bubble effects
- Floating input labels for better user experience
- Client-side form validation
- Password confirmation check
- Email and phone number validation
- Gender selection with radio buttons
- Branch selection dropdown
- Smooth field entrance animations
- Success alert with confetti animation
- Fully responsive for desktop and mobile devices

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the form
- **CSS3** – Styling, animations, and responsiveness
- **JavaScript (Vanilla JS)** – Form validation and interactivity

---

## 📌 Use Cases

- Student enrollment systems
- College or school registration forms
- Front-end form validation demo
- Portfolio project for web developers
